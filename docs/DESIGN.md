# 우리의장난감 디자인 기조

토스(TDS)에서 "한 화면 한 목적"과 해요체 라이팅을, 당근(SEED)에서 "강조색은 아껴 쓰기", 4px 그리드, 의미 토큰을 가져와 우리 앱에 맞게 고친 규칙이에요. 색상은 홍익 팔레트를 써요. UI를 바꿀 때는 이 문서를 먼저 따르고, 규칙을 바꿔야 하면 이 문서부터 고쳐요.

## 1. 원칙

1. **한 화면에는 목적 하나.** 홈은 계정 상태와 소개, 새 연구는 입력 양식, 프로젝트는 진행 상황과 결과만 보여줘요.
2. **주요 버튼은 화면당 하나.** `fill` 버튼은 한 화면에 하나만 둬요. 나머지는 `weak` 또는 텍스트 버튼이에요.
3. **입력은 최소로.** 기본값만으로 바로 시작할 수 있어야 해요. 라운드 수, 새 정보 기준, 모델 선택은 "고급 설정" 안에 접어 둬요.
4. **강조색은 아껴 써요.** 주요 행동은 Midnight Blue로, Medium Blue는 선택 표시와 핵심 수치에만 써요. 상태색은 심각도를 나타낼 때만 써요.
5. **숫자는 읽기 쉽게.** 계속 바뀌는 숫자에는 `tabular-nums`를 적용해요. 숫자와 단위는 크기를 약 2:1로 둬요(예: `51%` 28px, `남음` 14px).
6. **터미널로 보내지 않아요.** 로그인, 재시도, 이어서 실행처럼 앱이 할 수 있는 일은 앱 안에서 끝내요.

## 2. 색상 토큰

색상 프리셋은 **홍익 팔레트**예요. 컴포넌트에는 원시값 대신 아래 의미 토큰만 써요.

**팔레트 원본**

| 이름 | HEX | 구분 |
|---|---|---|
| Hongik Medium Blue | `#1833DB` | Primary |
| Hongik Midnight Blue | `#05014A` | Primary |
| Hongik White | `#FFFFFF` | Secondary |
| Hongik Black | `#000000` | Secondary |
| Hongik Bright Gray | `#EEEEF0` | Shade |
| Hongik Light Gray | `#D0D0D2` | Shade |
| Hongik Medium Gray | `#989A9F` | Shade |
| Hongik Dark Gray | `#53565F` | Shade |
| Hongik Stone Gray | `#313339` | Shade |
| Hongik Navy | `#020079` | Highlight |
| Hongik Azure Blue | `#0381FE` | Highlight |
| Hongik Mint | `#69EBFF` | Highlight |

**색 조합 원칙: Medium Blue 하나에 기대지 않아요**

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 뼈대 | Midnight Blue `#05014A` + White | 사이드바, 주요 버튼(`fill`), 내 말풍선, 선택된 라운드 칩, 브랜드 아이콘 |
| 바탕 | White `#FFFFFF` | 본문 배경, 카드 |
| 제목 | Black `#000000` | h1–h3, 선택된 탭 글자 |
| 포인트 | Medium Blue `#1833DB` | 링크, 선택 탭 밑줄, 핵심 수치(사용량 %), 헤드라인 두 번째 줄, 플랜 칩 |
| 어두운 배경 위 포인트 | Mint `#69EBFF` | 사이드바 선택 막대, 사이드바 포커스 링 |
| 보조 면 | Bright Gray `#EEEEF0` | 카드 안 보조 영역, 흰 버튼 hover |

- 넓은 면을 Medium Blue로 채우지 않아요. 파랑은 선, 글자, 숫자로만 보여줘요.
- Midnight Blue 위 글자는 흰색 또는 흰색 72%(`--on-brand-muted`)만 써요. Medium Blue는 Midnight 위에서 대비가 부족해요.

**의미 토큰** (대비는 흰 배경 기준으로 계산했어요)

| 토큰 | 값 | 대비 | 용도 |
|---|---|---|---|
| `--bg` | `#FFFFFF` White | — | 페이지 배경 |
| `--brand` | `#05014A` Midnight Blue | 18.9 | 사이드바, 주요 버튼, 내 말풍선 (`--brand-pressed`는 Navy `#020079`) |
| `--heading` | `#000000` Black | 21.0 | h1–h3 |
| `--surface` | `#FFFFFF` White | — | 카드, 입력창 |
| `--surface-weak` | `#EEEEF0` Bright Gray | — | 카드 안 보조 영역, weak 버튼 |
| `--line` | `#D0D0D2` Light Gray | — | 구분선, 테두리 |
| `--ink` | `#313339` Stone Gray | 12.6 | 제목, 본문 |
| `--ink-strong` | `#05014A` Midnight Blue | 18.9 | 홈 헤드라인, 강조 제목 |
| `--muted` | `#53565F` Dark Gray | 7.3 | 보조 본문, 메타 정보, 도움말 |
| `--disabled` | `#989A9F` Medium Gray | 2.8 | 비활성, placeholder, 장식 아이콘 (**본문 글자 금지**) |
| `--accent` | `#1833DB` Medium Blue | 8.3 | 링크, 선택 표시, 핵심 수치 (면을 채우지 않음) |
| `--accent-pressed` | `#020079` Navy | 16.4 | 주요 버튼 hover·눌림 |
| `--accent-weak` | `#E8EBFB` (Medium Blue 10%) | 7.0 | 선택 배경, weak 강조 버튼 배경 |
| `--focus` | `#0381FE` Azure Blue | 3.8 | 포커스 링, 진행 표시 (**작은 글자 금지**) |
| `--highlight` | `#69EBFF` Mint | 1.4 | 실시간 표시, 형광펜 강조 배경. 글자는 올리지 말고, 올려야 하면 Midnight Blue로 |

**모델 구분 색**: GPT는 Azure Blue `#0381FE`, Claude는 Midnight Blue `#05014A`예요. 색만으로 구분하지 않고 항상 이름(GPT/Claude)을 같이 보여줘요.

**상태색 (팔레트 밖 예외)**: 홍익 팔레트에는 빨강·초록·주황이 없어요. 오류·완료·주의는 파랑과 헷갈리면 안 되므로 아래 값만 예외로 써요. 이 세 색은 상태 표시에만 쓰고 장식에는 쓰지 않아요.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--danger` | `#D91F2F` (대비 5.0) | 오류 글자, 삭제·중단 같은 되돌릴 수 없는 행동 |
| `--positive` | `#03B26C` (대비 2.8) | 완료 점, 성공 토스트 아이콘 (글자에는 쓰지 않음) |
| `--warning` | `#FE9800` | 주의 점 (글자에는 쓰지 않음) |

**쓰지 않는 조합**
- Medium Gray·Azure Blue·Mint 위에 작은 글자, 또는 이 색으로 쓴 작은 글자
- Medium Blue와 Azure Blue를 한 요소 안에 나란히 두기(구분이 안 돼요)
- 순수 검정 `#000000` 본문. Black은 제목(h1–h3)과 로고에만 써요.

다크모드는 나중에 같은 토큰을 `prefers-color-scheme: dark`에서 다시 정의하는 방식으로 추가해요. 배경은 Midnight Blue `#05014A`, 글자는 Bright Gray `#EEEEF0`, 강조색은 Azure Blue `#0381FE`를 쓰는 것으로 시작해요. 색을 자동으로 뒤집는 방식(filter)은 쓰지 않아요.

## 3. 글자

- 폰트: `Pretendard, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- 줄 높이는 약 1.5배, 굵기는 400, 500, 600, 700만 써요.
- **13px보다 작은 글자는 쓰지 않아요.** 지금 8–12px로 된 선언이 약 90개예요. 모두 `caption` 이상으로 올려요.

| 토큰 | 크기/행간 · 굵기 | 용도 |
|---|---|---|
| `--t-display` | 30/40 · 700 | 홈 헤드라인 |
| `--t-title` | 26/35 · 700 | 화면 제목(프로젝트 이름) |
| `--t-heading` | 20/29 · 600 | 섹션 제목 |
| `--t-subheading` | 17/25 · 600 | 카드 제목 |
| `--t-body` | 15/23 · 400 | 본문, 입력 |
| `--t-caption` | 13/19 · 400 | 메타 정보, 도움말, 시간 |
| `--t-number` | 28/36 · 700 · tabular | 사용량 같은 핵심 수치 |

영문 대문자 eyebrow(`SUBSCRIPTION STATUS` 등)는 지우거나 한글 `caption`으로 바꿔요.

## 4. 간격, 모서리, 그림자

- 간격은 4px 단위예요: `4 8 12 16 20 24 32 40 56`. 묶음 사이 간격은 묶음 안 간격보다 커야 해요.
- 요소 사이 기본 간격 12px, 카드 안쪽 여백 20–24px, 콘텐츠 좌우 여백은 최소 16px이에요.
- 모서리: 입력창과 작은 버튼 8px, 버튼 12px, 카드 16px, 칩은 완전히 둥글게. 카드 안에 들어가는 요소의 모서리는 카드 모서리에서 안쪽 여백을 뺀 값으로 해요.
- 그림자는 불투명도 4% 이하로만 써요. 눈에 띄면 이미 과한 거예요. 층은 기본적으로 테두리로 나눠요.

## 5. 컴포넌트

- **버튼**: 종류는 `fill`(주요)과 `weak`(보조) 두 가지, 높이는 40, 48, 56px 세 가지예요. 로딩 중에도 버튼 너비는 그대로 두고 글자만 "…하는 중"으로 바꿔요.
- **입력**: 레이블은 위, 도움말은 아래에 한 줄로 둬요. 긴 설명은 접어 둬요. 파일 첨부는 브라우저 기본 버튼 대신 끌어다 놓는 영역으로 받아요.
- **토스트**: 성공이나 가벼운 알림은 화면 아래 토스트로 3초 보여줘요. 사용자가 뭔가 해야 하는 오류는 그 자리에 계속 남겨요.
- **다이얼로그**: ESC로 닫히고, 포커스는 다이얼로그 안에 머물고, 닫으면 원래 자리로 돌아가요.
- **탭**: 한 번에 보이는 탭은 4개까지예요. 나머지는 "더보기"에 넣어요. 좌우 화살표 키로 이동할 수 있어야 해요.
- **빈 화면**: 무엇이 비었는지 한 문장으로 알려주고, 다음 행동 버튼을 하나 둬요.

## 6. 움직임

- 시간은 150ms(색 변화, 누름)와 200ms(나타남, 사라짐) 두 가지예요.
- 나타날 때 `cubic-bezier(0,0,0.2,1)`, 사라질 때 `cubic-bezier(0.4,0,1,1)`을 써요. 튕기는 효과는 쓰지 않아요.
- 사용자가 움직임 줄이기(`prefers-reduced-motion`)를 켰으면 모두 꺼요.

## 7. 문구 (해요체)

토스의 라이팅 원칙 8가지를 따라요. "다듬습니다" 같은 합쇼체는 모두 "다듬어요" 같은 해요체로 바꾸고, 오류 메시지도 해요체로 써요.

1. 누르면 무슨 일이 생기는지 알 수 있게 써요.
2. 빼도 뜻이 통하는 단어는 빼요("앞으로", "해당", "진행").
3. 자리만 채우는 문장은 지워요.
4. 사용자가 이미 아는 내용은 반복하지 않아요.
5. 한 문장에 메시지 하나만 담고, 소리 내어 읽기 쉽게 써요.
6. 강요하거나 겁주지 말고 권해요.
7. 개발 용어(`.env`, `claims`, `MOCK`, `stdio`)는 사용자가 쓰는 말로 바꿔요.
8. 오류는 **무슨 일이 있었는지**와 **어떻게 하면 되는지**를 같이 써요.
   예: "Claude 로그인이 풀렸어요. 다시 로그인하면 멈춘 단계부터 이어서 할게요."

날짜와 시간은 한 가지 형식으로 통일해요. 오늘이면 `오후 3:43`, 다른 날이면 `9월 14일 오후 3:43`으로 써요. 서비스가 보내준 원래 문자열(`Sep 14 at 3:10pm (Asia/Seoul)`)을 그대로 보여주지 않아요.

## 8. 하지 않을 것

- 아이콘 대신 이모지나 기호 쓰기(⚖️ ✋ ↗ ↓)
- 카드마다 그림자나 그라데이션 넣기
- 섹션마다 영문 대문자 eyebrow 붙이기
- 한 화면에 `fill` 버튼 여러 개 두기
- 불친절한 UI를 설명 문단으로 메우기
- 13px보다 작은 회색 글자
